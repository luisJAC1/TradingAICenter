🔴 Known Bugs

Bug #1 — trading-brain Docker healthcheck always UNHEALTHY

The healthcheck command uses curl, which is not installed in the python:3.11-slim base image. The brain app itself runs fine on port 8791 — the healthcheck is just wrong.

FIX — Change in frontend/docker-compose.yml:
healthcheck: test: ["CMD", "python3", "-c", "import urllib.request; urllib.request.urlopen('http://localhost:8791/health')"] interval: 15s timeout: 5s retries: 5

Bug #2 — /api/brain/agent-status route never live-tested

The brain-integration.ts file was created Apr 21 but the Docker image rebuilt from cached layers that session — the route returned 404. Since claw-empire runs via tsx directly from source, a container restart should pick it up — but it's never been confirmed working end-to-end.

FIX — After fixing bug #1, restart claw-empire and test:
cd frontend && docker-compose restart claw-empire # Then test: curl -X POST http://localhost:8790/api/brain/agent-status \ -H "Authorization: Bearer <API_AUTH_TOKEN>" \ -H "Content-Type: application/json" \ -d '{"agent_id":"charts","status":"working","current_task":"Fetching NVDA data"}'
