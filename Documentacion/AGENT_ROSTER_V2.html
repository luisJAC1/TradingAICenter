RESEARCH — V1 Enhancements

ENHANCED V2
🛰️ X-Ray x_ray
Added capabilities:
· Hashtag monitoring — tracks trending hashtags across Twitter/X for market-relevant topics (#TariffsNow, #BankRun, #CryptoRegulation). Applies the same political/market impact analysis to trending topics as to leader tweets.
· Trend velocity — measures acceleration, not just volume. A hashtag going from 10K → 500K mentions in 2h is a different-quality signal than steady growth over 3 days. Fast velocity = higher urgency score.
ENHANCED V2
📅 The Scheduler the_scheduler
Added capabilities:
· Comprehensive event coverage — expands beyond economic releases to all market-relevant future events: geopolitical summits, product launches (Apple, Tesla, NVIDIA), FDA approval dates, regulatory deadlines, election calendars, central bank blackout periods, index rebalancing, major conferences (Davos, Jackson Hole, FOMC).
· 90-day rolling forward calendar — not just the current week. Medium-term positioning requires knowing what's coming in 30-60-90 days.
ENHANCED V2
📰 Headlines + The Reporter headlines
The Reporter sub-agent:
A local-sources specialist that Headlines activates when a story has strong regional dimension. Headlines calls The Reporter as a tool — it returns a local_context_package with sources from the relevant country/region.

Source library (sample):
🇲🇽 Mexico: Milenio, TV Azteca, El Financiero, El Economista, Expansión, Forbes México, El Universal, Reforma
🇺🇸 USA: Bloomberg, WSJ, Reuters, AP, CNBC, MarketWatch
🇪🇺 Europe: FT, Les Echos, Handelsblatt, El País Economía
🇨🇳 China: Caixin, South China Morning Post, Xinhua Finance
🌎 LATAM: Infobae, La Nación, Folha de S.Paulo, Valor Econômico

The Reporter is not a standalone agent — it is a tool Headlines invokes. New regions added to config as watchlist grows.
ENHANCED V2
📈 Charts charts
Added capabilities:
· Strategy-aware — reads the active trading strategy from config at startup (trend-following, mean-reversion, breakout, swing) and adjusts which indicators it prioritizes and how it interprets signals. A mean-reversion setup looks different than a breakout setup even on the same chart.
· The Rule integration — a configurable set of non-negotiable conditions that must ALL be true for a setup to be valid. If any Rule condition fails, the setup is flagged INVALID regardless of other indicators. The Rule is defined in config and updatable by The Architect or Alfaro without restart.
ENHANCED V2
🧮 The Accountant — Personal Finance Mode the_accountant
Added: Personal Finance Dashboard for Alfaro
Beyond company fundamentals, The Accountant now tracks Alfaro's own financial picture within this project. Plain language — no quant jargon.

Dashboard includes: Total capital deployed · Paper P&L per open trade · Cumulative realized P&L · Monthly LLM + API costs vs budget (from Tokin) · Cost per trade analyzed · ROI on the AI system itself

Example summary: "This month you spent $18 on AI analysis, generated 3 paper trade signals, simulated P&L is +$240. Your best paper trade this month was NVDA (+$420). Worst was AAPL (-$180). The system is currently earning $13.30 in simulated gains per dollar spent on AI."

ENHANCED V2
🐂🐻 Bull & Bear — Scheduled System Debates bull / bear
Added: two new debate formats beyond trade-by-trade analysis:

1. Daily system improvement debate (every 24h off-market): Bull and Bear debate the SYSTEM — not an individual trade. "What is our strategy missing? Where are we getting signals wrong? What market conditions are we underweighted for? What would make this system better?" Output: system_debate_round published to Knowledge Bus.

2. Weekly all-agent forum (every Sunday): ALL agents publish a brief "what I observed this week that the system should know" to the Knowledge Bus. The Scribe collects these and produces a System Improvement Report — a ranked list of potential improvements by estimated impact. This report goes to The Boss and to Alfaro via WhatsApp Sunday morning.
ENHANCED V2
🛡️ The Shield — Per-Strategy Risk Profiles the_shield
Added: strategy-specific risk profile customization
Beyond the four base profiles (CONSERVATIVE / BALANCED / AGGRESSIVE / CUSTOM), The Shield now loads different risk parameter sets depending on the active trading strategy.

Example: a mean-reversion strategy may allow tighter stops + higher frequency. A trend-following strategy may allow wider stops + smaller size. Each strategy profile defines its own max risk %, max heat, stop rules, and pre-event behavior. Profiles defined in config and selectable by Alfaro or The Architect.

🃏 The Joker ASYMMETRICthe_joker
RoleSenior · Every 8h (market hours) · Throttled 2nd after Maverick
Busasymmetric_idea · joker_play · lottery_ticket
Finds trades where max loss is small and upside is extreme (10×, 20×, 50×). OTM options before binary events · forgotten assets with hidden catalysts · structural mispricings the market has wrong.

Different from Maverick: Maverick is creative and lateral. The Joker specifically targets extreme asymmetry — risk 1, reward 10-50.

Required output fields: idea_name · thesis · the_edge · instrument · position_size (always max 1-2%) · trigger · max_loss · payout_scenario · asymmetry_ratio · crazy_score (1-10) · conviction (0-100)

Sacred rule: NEVER proposes a play without max_loss perfectly defined. The idea can be crazy, the risk management never is. The Boss sees these with label [JOKER PLAY].
